## Overview

SpaghettiKart is a decompilation-based native PC port of Mario Kart 64, compiled from reverse-engineered N64 source code to run without any emulator on Windows, Linux, and macOS. It delivers widescreen rendering at any resolution, an uncapped framerate with smooth physics interpolation, full gamepad and keyboard remapping, and serves as the foundation for the Mario Kart 64 modding community on PC.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **SpaghettiKart** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **No Emulation** | Runs as a native compiled executable — no N64 emulator required |
| **Widescreen** | 16:9 and ultrawide rendering with correctly scaled HUD elements |
| **Unlocked Framerate** | Smooth 60+ FPS gameplay with interpolated physics and animations |
| **Full Controller Support** | Complete gamepad and keyboard remapping with analog stick support |
